    Stage 5 · Embed

    Seven kinds of embedding

    Each tab explains one embedding type and shows it on the selected report. Dense vectors are approximated here with LSA (a 10-dimension SVD of TF-IDF) because a neural embedder cannot run in this page; the mechanics are the same.

    Stages 6–7 · Index and retrieve

    Hybrid search with reciprocal rank fusion

    Three channels rank the corpus independently, then RRF merges the ranks (score = Σ 1 / (60 + rank)). Try a query that uses words the reports never use, then turn query expansion on.

    Rank columns show each channel’s own rank (– = no match in that channel). Notifications have no findings, so the findings channel cannot see them.

    Stage 8 · Classify

    The cascade on the selected report

    Rules first, then neighbours, then a candidate set, then routing. The kNN pool holds only records with investigator findings; notifications are never training labels. With only 15 labelled records in this sample, neighbours often disagree with the rules, which is exactly the case routing exists for.

    Data: 23 NTSB Aviation Investigation Final Reports attached to this conversation (10 from Nov 1983–Jan 1984, 13 from Apr–Jun 2013), retrieved from CAROL. Reference CICTT labels are the author’s reading and await SME validation.

    Simplifications: LSA stands in for a neural dense embedder, character-trigram similarity stands in for contextual token embeddings, and the candidate-set threshold is illustrative, not calibrated.
